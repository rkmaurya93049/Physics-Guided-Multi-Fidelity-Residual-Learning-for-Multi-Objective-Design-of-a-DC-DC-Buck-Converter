# Analytical Dataset

`analytical_dataset.csv` is the 70,000-row low-fidelity dataset generated by `../../notebooks/analytical_model.ipynb` using Latin-hypercube sampling (seed 42).

The sampled design variables are L, C, switching frequency, load-current setting and switch on-resistance. Stored analytical outputs include duty cycle, inductor ripple/current-mode indicator, output-voltage ripple, conduction loss, switching loss, total loss and efficiency.

See `../../docs/METHODOLOGY.md` for equations/assumptions and `../../docs/REPRODUCIBILITY.md` for the rerun procedure.
