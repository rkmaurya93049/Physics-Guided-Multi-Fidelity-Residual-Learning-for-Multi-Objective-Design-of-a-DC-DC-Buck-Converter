# Figures

This directory separates the **curated research figures** from the original screenshot archive.

## `main/` — figures to show reviewers/professors

These four vector figures correspond to the scientific story in the final manuscript:

1. `workflow.svg` — verified multi-fidelity research pipeline.
2. `ltspice_reference.svg` — reference switching-level circuit and original 4–5 ms measurement protocol.
3. `residual_correction.svg` — analytical-to-LTspice transfer and residual-correction performance.
4. `pareto_front.svg` — final bounded 100-candidate surrogate non-dominated set with representative points.

Use these files in repository navigation, presentations, and research summaries. They are generated from the source-audited values used in the manuscript; they do not replace the source data or LTspice evidence.

## `archive/raw_uploads/` — original visual evidence

All originally uploaded screenshots are preserved here for provenance and traceability. They include development plots, LTspice waveforms, switching traces, startup checks, intermediate screenshots, and a few small/invalid image artifacts.

They are **not** all publication figures and should not be interpreted as equally authoritative. When a numerical claim matters, prefer the notebooks, CSV files, LTspice source files/logs, and the final manuscript over a screenshot.

No raw screenshot was deleted during repository cleanup.
