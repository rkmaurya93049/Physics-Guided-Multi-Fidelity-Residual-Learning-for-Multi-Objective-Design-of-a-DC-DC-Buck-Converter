# Representative LTspice Designs

- `Draft2.asc` — balanced selected candidate/manual engineering check.
- `Draft3_minRipple.asc` — minimum-ripple representative candidate.
- `Draft4_maxEfficiency.asc` — maximum **surrogate-predicted-efficiency** representative candidate.

The filenames are historical. `Draft4_maxEfficiency.asc` does **not** imply that LTspice measured it as the highest-efficiency candidate; the manuscript explicitly discusses the surrogate-ranking reversal.

The manuscript's main three-candidate validation comparison uses the common original 4–5 ms protocol. Some saved schematics/logs also contain later 9–10 ms manual engineering measurements; keep those interpretations separate.
