# LTspice Measurement Logs

Preserved direct simulation logs:

- `Draft1.log` — reference/baseline manual characterization.
- `Draft2.log` — balanced selected design manual characterization.
- `Draft3_minRipple.log` — minimum-ripple design manual characterization.
- `Draft4_maxEfficiency.log` — maximum surrogate-predicted-efficiency design, including the source-level averaging-window sensitivity measurements.

These logs are evidence, not a single uniform benchmark table: some entries correspond to later 9–10 ms engineering checks. The manuscript keeps the original common 4–5 ms representative-validation protocol distinct from these supplemental measurements.

Do not edit historical log values to make different measurement windows agree.
